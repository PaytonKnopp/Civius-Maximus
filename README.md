# Civilization-X (working title)

A turn-based 4X strategy game in the spirit of Civ 6, for playing online with friends (2–8
players) and built from the ground up to be modded: civs, leaders, units, rules, all as data.

> **Status:** design phase. No code yet. Start with the docs below.
