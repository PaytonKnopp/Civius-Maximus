# Setup guides

Everything in the game works without these: single player, hotseat, and online play with a
join code (straight from browser to browser) need no account and no server. These guides add
the optional parts.

| Guide | What it adds | Time | Cost |
|---|---|---|---|
| [Supabase](supabase.md) | Accounts, cloud saves (play on any device), public games anyone can join from a list | ~10 minutes | Free tier |
| [Desktop app](desktop.md) | The game as a Windows, macOS or Linux app | ~5 minutes with GitHub Actions, ~30 the first time on your own machine | Free |

The web version is already live on GitHub Pages (Settings → Pages → Source: GitHub Actions), and
rebuilds whenever `main` changes.
